¿Cómo verificar la base de datos en la terminal?

Comandos directos que puedes ejecutar en tu terminal / consola:

Bash / Docker
1. Entrar al cliente interactivo psql de PostgreSQL: docker compose exec db psql -U biblioteca_user -d biblioteca_db
2. Listar todas las tablas y sus dueños (dentro de psql): \dt
3. Ver estructura detallada y columnas de la tabla libros: \d+ libros
4. Ejecutar el comando inspector de Django: docker compose exec api python manage.py inspect_db
5. Ejecutar la suite de pruebas automatizadas de reglas: docker compose exec api python manage.py test app
